# NEXUS Enterprise HR Platform (Prototype)

A prototype of an enterprise HR and operations platform. The frontend is a large Next.js (TypeScript) app with many screens. The backend is a structured scaffold for a future Node.js and TypeScript API.

## Tech stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend (scaffold):** Node.js, TypeScript, Express-style modular layout

## Frontend screens
Dashboard, employees, attendance, leave, payroll, loans, recruitment, performance, training, organization and branches, documents, approvals, workflows, roles and permissions (RBAC), audit and activity logs, reports and analytics, notifications, projects, fleet, inventory, finance, GIS, drilling, face recognition, AI center, login with two-factor and forgot-password pages, and an employee portal.

## Backend
The `BACKEND` folder is a planned architecture only. It lays out the module boundaries (auth, employees, attendance, payroll, RBAC, workflows and more), but the business logic is not implemented yet.

## Run the frontend locally
```bash
cd FRONTEND
npm install
npm run dev
```
